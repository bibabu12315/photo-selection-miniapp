## 现在要做的 3 件事（按优先级）

### 第 1 件：提交小程序认证 ⭐ 最优先

**为什么最优先**：认证审核要 1-7 天，越早提交越好。而且它是当前唯一的硬阻塞——
没认证，微信会禁用「生成小程序码」和「分享给模特」，模特就拿不到入口。

**去哪做**：

1. 浏览器打开 `mp.weixin.qq.com`，用小程序管理员微信扫码登录
2. 左侧菜单 → **设置** → **基本设置** → **微信认证** → 点「开通」
3. 按向导填：主体类型选**个人**（或个体工商户，如果你已注册）
4. 个人主体认证：填姓名 + 身份证号 + 管理员微信扫码验证 + 交 30 元
5. 提交后等审核（个人主体通常 1-3 个工作日）

**判断成功**：后台「微信认证」状态变成「已认证」。

### 第 2 件：真机预览（手机跑一遍）

模拟器里跑通不代表真机没问题，尤其是图片加载和分享。

1. 微信开发者工具点顶部 **「预览」** 按钮
2. 弹出二维码 → 用**你的微信**扫码
3. 手机上打开小程序，依次验证：
   - [ ] 首页输入口令 `photoselect2026` → 绑定成功
   - [ ] 项目列表能看到「小王的夏日写真-2026.9」
   - [ ] 进详情页 → 照片数显示 11
   - [ ] 点「生成上传码」→ 6 位码正常出现
   - [ ] 照片缩略图在真机上能正常加载

> 真机进模特端：认证没过之前，手机上没法用小程序码/分享卡片进入。

### 第 3 件：稳定性测试

按方案 Phase 6 的 4 个场景，逐项验证：

| 场景 | 怎么测 | 通过标准 |
|---|---|---|
| 退出重进 | 模特端选几张 → 直接关掉小程序 → 重新进入 | 之前选的还在，计数正确 |
| 重复提交 | 提交锁定后再进模特端 | 显示「选片已提交」，不能再改 |
| 重新开放 | 摄影师端点「重新开放选片」→ 模特端重新进入 | 计数归零，可以重新选 |
| 大批量（300 张） | 电脑端一次拖 300 张上传 | 上传页不卡死，模特端分页加载正常 |

> 300 张的测试建议最后做，会消耗存储和流量配额。
