# 我要手动做的事

> 更新时间：2026-10-01 · 当前阶段：**V2.0 双端重构（已验收）** → **V2.1 多租户隔离 + 去掉口令（最新，看文末）**

---

## 这次改了什么

| 变化 | 说明 |
|---|---|
| 双端分开 | 摄影师 = 口令绑定（不变）；模特 = 有「我的拍摄」主页，能看到你给她的**全部**项目 |
| 一个项目最多 5 位模特 | 每人一条独立邀请链接，各选各的，结果按模特分组查看 |
| 套餐张数 | 新建项目可设上限，模特选满后不能继续勾 |
| 新增 2 个页面 | `guide`（身份引导，路人不再看到空白页）、`model-home`（我的拍摄） |
| 项目工作台重排 | 三区块按拍照流程：① 照片（上传引导）② 模特 x/5 ③ 结果 |
| 网页上传改向导 | 三步：输上传码 → 拖文件夹 → 看进度，envId 输入框已隐藏 |

---

## 第 1 步：新建两个数据库集合

云开发控制台 → 数据库 → 新建集合（**权限全部选「仅管理端可读写」**）：

| 集合名 | 用途 |
|---|---|
| `model` | 模特档案（openid + 备注名） |
| `invite` | 邀请记录（一个项目 × 一位模特一条） |

原有的 `project` / `photo` / `selection` / `admin` 保持不变。

**建议加的索引**（集合 → 索引管理 → 添加索引，都选「非唯一」）：

- `model`：`openid` 升序
- `invite`：`token` 升序、`modelId` 升序、`projectId` 升序
- `selection`：`projectId` 升序 + `modelId` 升序（联合索引）

不加索引也能跑，数据量大了会慢。

---

## 第 2 步：清空旧测试数据

旧数据结构和新结构不兼容（选片记录从「一个项目一份」变成了「一项目×一模特一份」），**必须清库**：

数据库 → 分别打开 `project`、`photo`、`selection` 三个集合 → 全选 → 删除。

> `admin` 集合**不要删**（你的摄影师身份在里面），删了要重新输口令绑定。
> 云存储里的旧图片（`p/` 开头的目录）可以留着，不影响；想清就在存储里删 `p/` 目录。

---

## 第 3 步：重新部署 3 个云函数

微信开发者工具 → 云开发 → 云函数 → 逐个右键「上传并部署（云端安装依赖）」：

1. `selection`（改动最大：新增 model/invite 逻辑、套餐上限校验）
2. `project`（新增邀请模特、小程序码按模特生成、延期）
3. `photo`（新增项目封面缩略图）

`admin`、`ping` 没改，不用动。

---

## 第 4 步：填电脑上传页的网址

打开 `miniprogram/env.ts`，把最后一行换成你的静态托管域名：

```ts
export const UPLOAD_PAGE_URL = 'https://cloud1-xxxx-1304825656.tcloudbaseapp.com/index.html'
```

域名在哪看：云开发控制台 → 静态网站托管 → 文件管理 → 上方「默认域名」。
（之前你已经在 8080 本地跑过上传页，把 `web/` 三个文件上传到静态托管即可。）

不填的话，小程序里点「去电脑上传」弹出来的网址会是占位文字。

---

## 第 5 步：验收（按顺序走一遍）

开发者工具里点「编译」，然后：

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 打开小程序 | 直接进「我的项目」（你已绑定摄影师）；项目列表为空，显示「还没有项目」 |
| 2 | 点「+ 新建」→ 填名字 → 套餐选 12 张 → 创建 | 跳到项目工作台，看到三区块 |
| 3 | 点「去电脑上传」 | 弹出网址 + 6 位上传码，可一键复制 |
| 4 | 电脑打开上传页 → 输码 → 拖文件夹 → 上传 | 三步向导走完，回到小程序看到「已上传 N 张」 |
| 5 | ② 模特 →「+ 邀请模特」→ 输入「小王」 | 出现一行「小王 · 已选 0 / 12 张」，右侧有复制链接/小程序码/移除 |
| 6 | 再邀请一位「小李」 | 变成「模特 2 / 5」 |
| 7 | 点「复制链接」→ 用自定义编译模式 `t=<token>` 打开 | 进入选片页，黑底网格，底部显示「已选 0 / 12 张」 |
| 8 | 选满 12 张后再点第 13 张 | 提示「最多选 12 张，先取消一张」，选不进去 |
| 9 | 提交选片 | 提示已提交；回到项目详情看到小王「已提交 12 张」 |
| 10 | ③ 结果 → 查看选片结果 | 顶部能看到「小王 12 张 / 小李 0 张」切换，文件名可一键复制 |

**模特端「我的拍摄」怎么测**：用另一个微信号扫码进一次邀请链接（或自定义编译进一次），
之后这个微信号再打开小程序，就会直接进「我的拍摄」并看到这个项目。

## 还剩下的两件事（不阻塞）

1. **小程序认证**：审核中。认证通过后，「小程序码」和「分享给模特」才可用；在那之前用「复制链接」+ 自定义编译自测。认证通过后可以删掉 `project-detail` 里复制链接弹窗里的那段说明文案。
2. **认证通过后**：分享卡片会自动带上第一位模特的邀请链接（代码已写好）。

---

## 出问题先看这里

| 现象 | 原因 / 处理 |
|---|---|
| 页面空白或一直转圈 | 云函数没部署完，或 `model`/`invite` 集合没建 |
| 提示「你没有被邀请进这个项目」 | 旧数据没清干净，或链接对应的模特被移除了 |
| 邀请模特报「最多 5 位」 | 设计如此，先移除一位 |
| 上传页验证码失败 | 码 5 分钟过期，回小程序点「刷新上传码」 |
| 上传页报跨域/上传失败 | 已知现象，文件其实传上去了，由云端核验；看第 3 步进度条变绿即可 |

# V2.1 多租户隔离 + 去掉口令（本轮改动）

对外推广前的必修课。改了两件事：

| 变化 | 说明 |
|---|---|
| 项目归属到人 | `project` 新增 `ownerOpenid`；列表只返回自己的项目；查看/删除/延期/上传码/邀请模特全部校验归属，别人的项目一律「无权限」 |
| 去掉摄影师口令 | 任何人打开小程序点「我是摄影师」即开通。口令降级为一次性迁移密钥（`ADMIN_BIND_KEY`），不再对用户暴露 |

---

## 步骤 1：重新部署 2 个云函数

微信开发者工具 → 云开发 → 云函数 → 右键「上传并部署（云端安装依赖）」：

1. `project`（改动最大：所有接口加归属校验）
2. `admin`（bind 去掉口令校验 + 新增 claimLegacy）

`selection`、`photo`、`ping` 本轮没改，不用动。

---

## 步骤 2：确认环境变量还在

云开发控制台 → 云函数 → `admin` → 配置 → 环境变量，确认 `ADMIN_BIND_KEY` 还在（值就是你的 `photoselect2026`）。

**别删它**——步骤 3 的迁移要用它做密钥校验。以后它也只用于这类高危操作，不再对用户可见。

---

## 步骤 3：把老项目归到你名下（一次性，必须做）

因为老项目没有归属字段，不改的话它们会在列表里消失（列表只查 `ownerOpenid = 你`）。

操作：云开发控制台 → 云函数 → `admin` → **云端测试** → 测试参数填：

```json
{ "action": "claimLegacy", "key": "photoselect2026" }
```

点「运行测试」，返回类似：

```json
{ "ok": true, "data": { "updated": 3, "owner": "oXXXX" } }
```

- `updated` = 被认领的项目数，和你现有的项目数一致就对了
- `owner` 留空也行：没传 openid 时会自动归给**最早开通的摄影师**（就是你）
- 报「找不到归属人」→ 先在小程序里点一次「我是摄影师」再回来跑

---

## 步骤 4：验收

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 编译小程序 | 直接进「我的项目」，**老项目都还在**（说明迁移成功） |
| 2 | 新建一个项目 → 上传 → 邀请模特 | 全流程照旧 |
| 3 | 用另一个微信号打开小程序 | 出现身份引导页，两个按钮：我是摄影师 / 我是模特 |
| 4 | 那个微信号点「我是摄影师」 | 直接进入它的摄影师工作台，**列表是空的**（看不到你的项目） |
| 5 | （可选）用它的身份复制你的项目 id 去调接口 | 返回「无权限：这不是你的项目」 |

第 4 步是本次改造成败的关键验证：**另一个微信号必须看不到你的任何项目**。

---

## 本轮之后的已知缺口（不阻塞，但推广前建议补）

| 缺口 | 影响 | 建议 |
|---|---|---|
| 没有配额 | 有人挂 5000 张图，云开发账单会涨 | 加免费额度：同时 3 个项目 / 单项目 500 张 / 存 30 天 |
| 换微信后身份丢失 | 摄影师换微信号，项目全「消失」 | 加 6 位迁移码：老微信生成、新微信输入即接管 |
| 无任何找回手段 | 用户来问「我的项目呢」，你没法帮他 | 上面那条迁移码顺便解决 |
