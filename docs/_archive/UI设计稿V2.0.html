    10. 模特端状态说明卡片与选片页的四种状态
    9:41摄影选片···
    状态规则
    待选片灰
    项目已邀请，模特还没选过任何一张
    选片中琥珀
    已选至少 1 张但未提交，可继续修改
    已提交绿
    模特已提交，列表只读；摄影师可解锁重选
    已过期红
    超过项目有效期，模特看到但无法进入选片
    加载失败重试
    弱网时显示「加载失败，点此重试」，不静默失败
    • 四个状态在摄影师端与模特端用同一套颜色和文案
    • 过期由服务端判断，前端不信任本地时间
