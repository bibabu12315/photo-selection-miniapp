| 监控项 | 在哪看 | 异常阈值 |

1. `ERR_UNKNOWN` —— 未捕获异常，说明有分支没处理
2. 存储容量**只增不减** —— 说明归档或删除没真的删掉文件

## 七、回滚方案（事先想好，出事才不慌）

| 场景 | 回滚动作 |
|---|---|
| **云函数出问题** | 云开发控制台 → 云函数 → 版本管理 → **回退到上一版本**（云函数有版本历史，不需要重新写代码） |
| **网页端出问题** | 静态托管 → 版本管理 → 回退；或先在本地修好再重新部署 |
| **小程序端出问题** | 小程序无法即时回退。**只能在公众平台提交新版本并加急审核**，或紧急「暂停服务」 |
| **数据被写坏** | 云开发控制台 → 数据库 → 集合**导出备份**恢复。**发布前先做一次全量导出** |

**发布前必做**：云开发控制台 → 数据库 → 每个集合**导出一份 JSON 备份**存本地。这是回滚的最后一道保险。
