四、体验增强清单

第 6 点讨论产物 · 按「本轮 UI 顺手做」与「需要后端排期」分档

本轮 UI 就能做（改样式/前端逻辑）

  • 大图页手势补齐：双指缩放、双击放大——模特看细节必用（现有 gest.wxs 基础上扩展）
  • 选片即时震动反馈：wx.vibrateShort(15ms)，选中/取消轻震一下，比纯视觉更跟手
  • 提交前确认弹窗：「将提交 12 张，提交后仍可修改」——降低误触焦虑
  • 网页端大图预览：点照片墙任意图 → 深色浮层大图 + 键盘 ←/→ 翻页、Esc 关闭
  • 结果页按模特筛选：多模特项目里分人查看/复制清单
  • 空状态带引导：每个空页面都给「下一步动作」按钮，不留死胡同

需要后端/云函数排期（先记录，不承诺）

  • 模特身份绑定 + 历史回看（第 3 点需求）：邀请进入时把 openid 与模特记录关联；「我的拍摄」改为查本人全部未过期项目。回看受 30 天留存限制，原图不上云不变
  • 提交即锁定的后端支撑：SELECTION_SUBMITTED 后拒绝模特端改选请求，「重新开放」= 项目状态回退 SELECTING 并通知
  • 订阅通知：模特提交/项目到期时提醒摄影师——对应已搁置的 T-P2-3，UI 预留开关位
  • 照片搜索：按文件名搜（绚篇同款搜索框），千张以上项目有用
  • 项目归档视图：已导出的项目折叠进「历史」，列表只留进行中
  • 操作日志真实落库：动态时间线的数据源，需要在状态流转时写记录
