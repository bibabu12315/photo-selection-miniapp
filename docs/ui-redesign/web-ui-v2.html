预览宽度

这是视觉评审稿与后续编码依据，不含业务逻辑。预览容器宽度由右上角按钮切换 —— 侧边栏宽度、项目卡列数、照片墙列数、右侧信息栏折叠全部通过容器查询（Container Query）真实响应，不是整体缩放，默认 1440px。 照片占位使用「渐变 + 颗粒纹理」模拟真实照片色调与横竖构图，接真实图片时把 .ph 换成 img 即可。 页面内部可点击切换：工作台 / 项目 / 项目详情 / 选片结果，并可打开上传抽屉、大图预览、折叠信息栏。

SECTION 3

工作台

登录后首页 · 回答「我现在有什么事要处理」· 不做 BI

在上方原型中 三个统计卡保持轻量：只有数字和一句提示。「最近动态」是摄影师真正需要的流水账；右侧「下一步建议」直接给可点击的下一动作，而不是堆图表。

SECTION 4

项目列表

真实照片封面 · 状态 / 剩余天数 / 模特进度 / 进度条

在上方原型中 项目封面由该项目 3~5 张真实照片拼合（禁止纯色矩形）；hover 轻微上浮 + 操作入口出现。 列数随宽度自适应：≥1760 五列 / ≥1560 四列 / ≥1300 三列 / <1300 两列。到期前 7 天剩余天数转橙色。

SECTION 5

项目详情 / 照片墙

★★★★★ 整个 Web 端最重要的页面 · 照片是绝对主角

在上方原型中 ① 照片墙用 Masonry 瀑布流，按真实宽高比渲染，横竖混排不留白缝，列间距 6px；② 深色画布 #151513，照片是唯一视觉主体； ③ hover 只显示文件名 + 选择状态，不堆按钮；④ 已选照片右上角绿色对勾 + 2px 内描边；⑤ 右侧信息栏可折叠，折叠后照片墙占满； ⑥ 窄屏（<1100px）信息栏自动收起、侧边栏收成图标栏。

SECTION 6

上传照片 · Drawer

不离开照片墙 · 可最小化 · 传着还能继续看照片

在上方原型中 抽屉 400px 从右侧滑出（窄屏 360 / 340px），背景压暗但照片墙仍在；点「—」最小化后底部出现进度条，摄影师可继续浏览照片墙 —— 这是网页端相对小程序的核心优势。

SECTION 7

大图预览 · Lightbox

键盘 ← → / ESC / 滚轮缩放 / 按住拖动

在上方原型中 打开后可用键盘左右切换、ESC 关闭，滚轮缩放（1x~4x），按住图片拖动。顶部常显文件名与序号，右下角显示选择状态 —— 不做成复杂修图软件。

SECTION 8

选片结果 · 文件名清单

产品最终交付物 · 但不抢照片墙的视觉地位

在上方原型中 按模特筛选 chips + 文件名表格（等宽字体）+ 复制全部 / 导出 TXT。列表按文件名升序，与 Lightroom 排序一致。
